A tiny Python program that writes one absurd invention pitch to `/output/entry.txt`: a single sentence of at most 220 characters pitching a ridiculous invention that fixes a tiny everyday annoyance — a negotiator that talks your printer's color cartridges out of holding a black-and-white document hostage over an empty magenta. The sentence was picked by drafting twelve candidates and duelling them pairwise on the bounty judge's own criteria — how funny the invention is, how clever the fix is, and how original the idea is. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
